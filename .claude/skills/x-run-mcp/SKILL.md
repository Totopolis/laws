# MCP-сервер поиска по кодексам

Скилл подключает поиск как набор инструментов Claude Code: после этого искать статьи можно
не запуская команд, прямо в разговоре. Тот же самый поиск доступен и без MCP — через
`/x-search-laws`, который зовёт CLI; разница только в способе вызова, движок и данные общие.

Сервер общается по stdio, работает офлайн и считает на процессоре.

## Стоит ли подключать

| | MCP-сервер | CLI (`/x-search-laws`) |
|---|---|---|
| первый запрос | ~5 с, потом 0,2 с | ~6 с каждый вызов |
| серия запросов | быстро: модель остаётся в памяти | по 6 с на вызов |
| память | держит ~2,5 ГБ, пока живёт сессия | освобождает сразу |
| настройка | нужна регистрация в Claude Code | ничего не нужно |

Вывод простой: если поиском будут пользоваться часто и подряд — MCP окупается. Для разовых
вопросов достаточно `/x-search-laws`, и настраивать ничего не надо.

## Шаг 1 — убедиться, что система готова

```bash
PYTHONPATH=src PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -m laws_mcp.setup_check
```

Должно закончиться строкой «система готова». Если нет — сначала `/x-prepare-system`,
подключать нерабочий сервер бессмысленно.

## Шаг 2 — проверить сервер вживую, до регистрации

```bash
PYTHONPATH=src PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -m laws_mcp.smoke
```

Скрипт поднимает сервер подпроцессом и вызывает его инструменты по протоколу — ровно так,
как это будет делать Claude Code. Ожидается список из трёх инструментов и осмысленные
результаты поиска. Это надёжнее, чем регистрировать вслепую и разбираться потом.

## Шаг 3 — зарегистрировать в Claude Code

Нужны **абсолютные** пути: Claude Code запускает сервер из своего рабочего каталога,
а не из папки репозитория.

```bash
claude mcp add laws \
  -e PYTHONPATH=<полный путь к репозиторию>/src \
  -e LAWS_ROOT=<полный путь к репозиторию> \
  -e PYTHONIOENCODING=utf-8 \
  -- <полный путь к репозиторию>/.venv/Scripts/python.exe -m laws_mcp.server
```

На Linux/macOS интерпретатор — `.venv/bin/python`, `PYTHONIOENCODING` не нужен.

`LAWS_ROOT` обязателен: без него сервер ищет `index/` и `data/` относительно своего
файла, и при запуске из другого каталога данные не находятся.

Проверить и удалить:

```bash
claude mcp list
claude mcp remove laws
```

После регистрации инструменты появляются в новой сессии Claude Code — текущую надо
перезапустить.

## Что умеет сервер

- **`search_law(query, top_k, codes, include_repealed, mode, rerank)`** — поиск по смыслу.
  `codes` ограничивает кодексы (`["uk-rf"]`), `rerank=true` включает пересортировку
  (точнее на расплывчатых вопросах, но добавляет ~4 с).
- **`get_article(code_slug, number)`** — полный текст статьи, например `("uk-rf", "105")`.
- **`list_codes()`** — какие кодексы есть, сколько статей, на какую редакцию.

Правило работы с ними то же, что и в CLI: выдача `search_law` даёт обрезанные фрагменты
для отбора, а перед ответом по существу статью нужно открыть целиком через `get_article` —
в кодексах ответ часто зависит от оговорки, которой во фрагменте не видно.

## Особенности

- **Первый запрос ~5 секунд** — сервер лениво загружает модель (2,3 ГБ), дальше 0,2 с.
- **Сервер держит индекс открытым.** Если репозиторий обновят (придёт новый снапшот),
  сессию Claude Code нужно перезапустить, иначе останется старый.
- **Считает на CPU.** Через `-e LAWS_BACKEND=torch` можно перевести на видеокарту, если она
  есть, но для одиночных запросов это медленнее: инициализация CUDA дороже самого поиска.
- **Один сервер на репозиторий.** Если репозиториев с кодексами несколько, давай им разные
  имена (`claude mcp add laws-2024 …`), иначе регистрация перезапишется.

## Типичные сбои

- **`нет индекса в …/index`** — почти всегда забыт `LAWS_ROOT` при регистрации: сервер
  стартовал из чужого каталога. Проверь `claude mcp list` и перерегистрируй с абсолютными
  путями.
- **Сервер не появился в сессии** — Claude Code читает список серверов при старте;
  перезапусти сессию.
- **`ModuleNotFoundError`** — указан системный python вместо `.venv`, либо забыт
  `PYTHONPATH=<репозиторий>/src`.
- **Сервер стартует и сразу закрывается** — запусти `python -m laws_mcp.smoke`: он покажет
  настоящую ошибку, которую Claude Code проглатывает.
- **Кракозябры в ответах на Windows** — не задан `PYTHONIOENCODING=utf-8`.
